Accessibility Statement

Jordan Licon Photography is committed to making the website usable and accessible for visitors with diverse needs, screen sizes, browsing devices, and assistive technologies. The goal is simple: every visitor should be able to review services, browse portfolio work, read pricing information, and contact the studio without unnecessary friction.

Ongoing improvements

The site uses semantic HTML, descriptive page titles, visible links, readable contrast, responsive layouts, and keyboard-accessible navigation wherever practical. Images are given descriptive alt text when they communicate meaningful content, while decorative images are treated in a way that keeps screen-reader output focused. Text sizing, spacing, and section hierarchy are reviewed as new portfolio pages, blog posts, and service pages are added.

Because the website includes large photography galleries, embedded video, booking links, third-party forms, and locally hosted media, accessibility is treated as an ongoing process rather than a one-time checklist. As new work is added, the site will continue to be tested for mobile readability, keyboard access, clear focus states, descriptive calls to action, and content structure that works for both visual browsing and assistive technology. The site is also reviewed for practical usability details such as touch target size, predictable navigation, and simple ways to return to the main portfolio.

Known areas of attention

Some third-party embeds, including booking or form tools, may have accessibility behavior controlled by their own platforms. When possible, the site provides direct email links and clear alternate contact paths so visitors are not dependent on a single tool. Large image galleries are also built to preserve visual quality while keeping page interaction simple.

Visitors can also use standard browser zoom, screen-reader tools, keyboard navigation, and mobile accessibility settings while browsing the site. The design avoids hiding essential service information inside images alone, so pricing, booking paths, portfolio categories, and contact information remain available as readable text.

Feedback

If you have difficulty accessing any part of the website, email info@jordanliconphotography.com with the page URL, the device or browser you are using, and a short description of the issue. Accessibility feedback is reviewed directly and used to improve the site experience.

Accessibility priorities

The site is reviewed for practical accessibility details that matter to photography clients: readable service descriptions, descriptive page links, alternate contact paths, mobile-friendly layouts, and portfolio navigation that does not depend on a single interaction style. When new galleries, blog posts, videos, or booking paths are added, the goal is to keep core information available as text so visitors can understand services even if media files load slowly or third-party embeds behave differently across devices.
